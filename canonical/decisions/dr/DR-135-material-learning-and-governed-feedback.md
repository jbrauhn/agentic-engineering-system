# DR-135 — Material Learning Records and governed feedback

**Status:** Adopted

## Decision

Create `Learning Record [A2]` only for material evidence-backed conclusions using the test: **Would losing this conclusion materially reduce the quality of future engineering decisions?**

Loop closure requires a learning disposition, not automatic Learning Record creation. The minimum disposition set supports material Learning created, existing Learning qualified/reinforced/superseded, Experiment updated/concluded, and no material Learning identified.

Learning is informative, not self-authorizing. Consequential change routes through existing Decision/ADR/authority/configuration/change mechanisms. Pre-authorized adaptive behavior may operate inside explicit existing OA/policy/adaptation boundaries, but may not self-expand authority or weaken policy.

## Rationale

This operationalizes DR-105 while avoiding artifact theater and opaque self-modification.

## Consequences

Issued Learning history is non-destructive. Later Evidence may qualify current reliance without rewriting history. No new Learning Summary, Recommendation, or Adaptation A1/A2 is introduced.
