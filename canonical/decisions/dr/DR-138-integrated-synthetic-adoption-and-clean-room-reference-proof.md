# DR-138 — Integrated synthetic adoption and clean-room reference proof

**Status:** Adopted

## Decision

Adopt one deliberately imperfect generic synthetic organization and integrated reference loops to prove cross-domain adoption behavior. The fixture must include both Capability and Engineering Health deficiencies, agent-operability/authority constraints, allowed/denied direct Work Management behavior, and governed remediation with Evidence and independent Validation.

Adopt a clean-room reference harness whose planning actor receives only the assembled versioned distribution plus a supplied OEB/Product baseline and is evaluated against Contract Proof M's eight rubric dimensions. The reference harness proves the input boundary and rubric mechanics; final Part 1 evidence should additionally include a genuinely fresh external Human/agent adoption run before Human Owner final acceptance.

## Consequences

- No new L1-L A1/A2 type is introduced.
- Existing Contract/L1 semantics remain authoritative.
- Technology-specific packaging and UX mechanisms remain replaceable.
